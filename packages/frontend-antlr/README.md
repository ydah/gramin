# @gramin/frontend-antlr

ANTLR4 grammar frontend for gramin.

## Installation

```sh
npm install @gramin/frontend-antlr
```

The package exports `antlrFrontend`, `FRONTEND_ANTLR_ID`, and
`FRONTEND_ANTLR_VERSION`. It converts ANTLR4 parser grammars, including split
parser/lexer grammars, to the versioned Grammar IR contract from `@gramin/core`.
