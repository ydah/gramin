# @gramin/frontend-bnf

BNF and EBNF grammar frontend for gramin.

## Installation

```sh
npm install @gramin/frontend-bnf
```

The package exports `bnfFrontend`, `FRONTEND_BNF_ID`, and `FRONTEND_BNF_VERSION`.
It converts BNF and EBNF grammars to the versioned Grammar IR contract from
`@gramin/core`.
