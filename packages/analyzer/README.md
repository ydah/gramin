# @gramin/analyzer

Deterministic structural analysis for versioned gramin Grammar IR documents.

## Installation

```sh
npm install @gramin/analyzer
```

The package exports `analyzeGrammar` and `ANALYZER_VERSION`. Input must conform to the
Grammar IR contract published by `@gramin/core`.

See the [metrics catalog](https://github.com/ydah/gramin/blob/main/docs/metrics-catalog.md)
for metric definitions and comparison guarantees.
