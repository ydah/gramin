# @gramin/frontend-peg

Peggy and PEG.js grammar frontend for gramin.

## Installation

```sh
npm install @gramin/frontend-peg
```

The package exports `pegFrontend`, `FRONTEND_PEG_ID`, and `FRONTEND_PEG_VERSION`.
It converts scannerless PEG expressions to the versioned Grammar IR contract from
`@gramin/core`.
